# Password Generator

A Python-based Password Generator application developed as part of the Oasis Infobyte Python Programming Internship.

## Features

- Generate secure random passwords
- Custom password length
- Uppercase letters
- Lowercase letters
- Numbers
- Special characters
- Input validation
- Tkinter graphical user interface
- Copy generated password to clipboard
- Uses Python's `secrets` module for secure random generation

## Technologies Used

- Python
- Tkinter
- Secrets
- String
