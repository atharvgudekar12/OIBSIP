# Python Task 4 - Chat Application

## Project Overview

This project is a real-time multi-client chat application developed using Python.

The application uses socket programming for communication between the server and multiple clients and Tkinter for the graphical user interface.

## Features

- Real-time messaging
- Multiple clients can connect to the server
- Username-based login
- Duplicate username validation
- Online users list
- Message timestamps
- Join and leave notifications
- Send button
- Enter key to send messages
- Connection error handling
- User-friendly GUI

## Technologies Used

- Python
- Socket Programming
- TCP/IP
- Tkinter
- Multithreading
